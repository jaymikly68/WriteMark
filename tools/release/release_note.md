### 本次更新（v1.6.0 → v1.6.1）

**视频：取消导出不再产生截断文件（真实缺陷修复）**

- 修前：导出途中点「取消」，循环虽然停了，但仍会走完「关闭 writer → 封装音轨 → 写出输出」
  的正常收尾，于是**生成一个只有开头几秒的坏视频**，并弹出「任务已完成」。
- 修后：取消即抛出 `WatermarkCancelled`，跳过全部收尾步骤——
  **不生成任何输出文件**，状态栏显示「已取消：未生成输出文件」，
  既不谎报成功也不当失败处理。临时文件仍由 `finally` 清理。
- 点窗口「关闭」的行为**不变**：程序直接退出，不会转为后台继续导出
  （后台守护 watch­dog 早已移除，也不会恢复）。

**Word 插入任务的退出/关闭（只加测试 hook，不改真实速度）**

- 给后台任务加了仅测试环境可用的可控阻塞点（生产恒为空，有断言保证），
  **没有给真实插入加任何 sleep**——30 页文档一两秒完成是正常速度。
- 新增回归测试：插入进行中点关闭，验证程序能在限时内终止工作线程、
  界面忙碌态正确、且**不留下半截输出文件**。

**水印层级（结论：Word 架构限制，不改代码，已写入 README「限制」）**

- 实测确认文字水印落在页眉层（`behindDoc=1` / `wrapNone` / 相对页面定位），
  而正文图片属于正文层。Word 的绘制顺序是**先页眉后正文**，
  所以正文图片必然盖住水印——这与 Word 内置水印的表现完全一致。
- 要让水印压在图片之上只能把 `behindDoc` 改成 `0`，但那样水印会压住正文文字，
  属于产品取舍而非缺陷，故本版不改。
- 新增结构测试钉住当前层级，并已提前验证：识别与清除只依赖水印自身的私有标记，
  **不依赖 `behindDoc`**，将来若决定切换只改一处属性即可，删除逻辑不受影响。

**删除安全边界补测**

- 「文字 + 图片 + 用户自己的衬于文字下方图片」三者共存时，
  即使用户选择「都去除」，用户自己的图片与正文也**必须保留**
  （WriteMark 标记与用户内容始终可区分）。

**测试**

  `tests/gui/test_close_during_insert.py`（插入中关闭）、
