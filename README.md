# WriteMark（Word / 视频一键水印工具）

## 一、简单介绍

WriteMark 是一个 Windows 桌面小工具，用来给 **Word 文档**和**视频**加水印、去水印：

- 图形界面（Python + PySide6），无需打开 Word 即可**实时预览**效果；
- Word 侧以标准 OOXML 方式把水印写进**正文层、浮于文字与图片之上**（`behindDoc=0` + 最大 `relativeHeight`），正文图片不再遮挡水印，WPS 与 Microsoft Word 都能正常显示；
- 视频侧对**每一帧**做合成，而不是只改封面，因此极难被抹掉；
- 已打包为单个 `WordWatermark.exe`，双击即用，不需要安装 Python。

## 二、功能

**Word 水印**

- **文本水印与图片水印可同时叠加**，两类参数（角度 / 透明度 / 缩放 / 偏移）各自独立。
- **中文字体与西文字体分别指定**（与 Word 字体对话框同语义）：汉字、中文标点走中文字体，字母、数字、半角符号走西文字体。字体列表来自**本机已安装字体**（读取 Windows 字体注册表），**不会启动 Word**，无需授权。
- **不改动原文件**：默认另存为 `桌面/<原名>WaterMark.docx`，输出路径可自定（若与源文件同名会自动加 `_水印` 后缀保护）。
- **防去除加固（可选）**：平铺满页水印 + 伪装显示名（识别标记改藏在 `wp:docPr/@descr`，Word 会保留且不影响本工具识别与清除），抬高删除成本。
  > 注：v1.6.2 起水印统一写在**正文层**，加固不再分写到页眉/页脚；「多份冗余」体现为**每个正文段落各有一份**，页(page)为坐标基准，视觉上重叠成一层。
- **实时预览**：改任意参数约 0.2 秒后自动刷新 A4 示意预览。

**视频水印**

- **逐帧写入**，支持 mp4 / mkv / avi / mov / wmv / flv / webm（随包附带 ffmpeg，无需系统安装），**原音轨自动保留**。
- 文字与图片各有独立的**播放方式**（固定 / 滚动 / 固定+滚动）、**位置锚点**与**拖拽定位**（红十字=文字，蓝十字=图片）。
- 文字水印同样支持中西文字体分别设置，中英文混排（如 `机密 CONFIDENTIAL`）按字符类别自动分流。
- **生效时段**：填一行 `1.0-2.0`，水印只在第 1~2 秒出现，其余时刻画面干净，用于遮挡某几秒才出现的敏感信息。
- 导出分辨率 / 帧率 / 画质可选，处理中可随时**取消**——取消后**不会生成输出文件**（不会留下半截视频）。

**图片水印来源**

- 支持 png / jpg / jpeg / webp / pdf；**多页 PDF 可任选其中一页**作为图片水印。

**清除水印**

- 一键清除 WriteMark 自己插入的水印；同时有文字与图片时会让你选择删哪一种。
- **本工具水印与「Word 自带 / 你自己添加的水印」共存时**：会弹出四选一框，让你明确选择——**仅清除本工具水印** / **仅清除 Word/用户水印** / **两者都清除** / **取消**。选择「仅清除 Word/用户水印」时，WriteMark 自己插入的水印会原样保留；选择「取消」则不动任何内容。

## 三、使用

1. 运行 `WordWatermark.exe`（或源码方式 `python main.py`）。
2. **先完全关闭 WPS / Word** —— 文件被占用时工具会明确提示，不会默默失败。
3. 点「浏览...」选择 `.docx` / `.doc`，程序自动给出默认输出路径。
4. 勾选「启用文本水印」/「启用图像水印」（可同时启用），分别设置参数；文本水印里分别选中文字体与西文字体。
5. 用「水平 / 垂直偏移」或直接在预览上拖拽调整位置；预览会实时刷新。
6. 点 **一键插入水印** 或 **一键清除水印**。插入完成后会弹「任务已完成」提示。

**视频页**：选择视频与输出路径 → 设置文字/图片水印与播放方式 → 点「预览水印效果」确认（可用「时刻(秒)」右侧 ▲/▼ 按 0.5 秒步进查看不同时刻）→ 点「开始加水印」。

**插入后看不到水印？** 请确认：① Word/WPS 处于**页面视图**（草稿 / Web 版式不显示浮动型水印图形）；② 文件未被 Word/WPS 打开；③ 处理 `.doc` 时本机装有 Microsoft Word。

**关闭窗口** = 直接退出程序：会先清理后台线程再退出，不会驻留后台或托盘。

## 四、限制

- **仅 Windows**。`.docx` 无需安装 Office；**`.doc`（Word 97-2003）必须本机安装 Microsoft Word**（走 Word 自动化，纯 Python 无法读写该格式）。
- **PDF 只能作为图片水印的来源**，不能作为被加水印的目标文档。
- **没有绝对删不掉的水印**：`.docx` 本质是 zip，任何人都能解压改 XML 后重新打包。本工具的加固只是抬高门槛（详见日志中的说明），不是绝对防线。
- **视频逐帧重编码**：长视频耗时较长属正常代价；画质由导出设置决定，不会优于源片。
- **清除范围有安全边界**：WriteMark **默认只删除自己能识别、确认属于自己插入的水印**。若未检测到 WriteMark 水印，但发现疑似 Word 原生 / 用户自制的水印候选，程序会**先弹窗征求确认**（默认「否」）；你选择否或取消，则**不删除任何内容**。检测失败时同样直接取消本次清除，不会退化成扩大删除范围。
- **原生水印识别属于启发式判断**：它按「衬于文字下方、负 z-index、VML textpath」等特征推测，不能 100% 区分所有用户图形与水印，请勿期待它替代人工判断。
- **水印显示层次（已优化）**：自 v1.6.2 起，水印改为写入**正文层并浮于内容之上**（`behindDoc=0` + 最大 `relativeHeight`），正文里的图片不再遮挡水印；水印仍保留私有标记，一键清除只删 WriteMark 自己插入的部分，不会碰用户正文或用户自制图形。早期版本（≤v1.6.1）水印落在页眉层（`behindDoc=1`），会被正文图片盖住，属 Word「先画页眉后画正文」的绘制顺序。
- 历史版本曾提供「后台守护（水印被删自动补回）」，**该功能已在当前版本移除**；关闭窗口即退出程序。
- 自动化测试：`pytest -q`（用例数量随版本迭代变化，以实际输出为准；最近一次全量验证为 **181 passed, 3 xfailed，0 failed**）。
  > 其中 3 条 `xfail` 是刻意保留的**已知风险/技术债刻画**，不是回归缺陷，请勿删除（详见 `tests/unit/test_clear_any_scope.py` 与 `tests/unit/test_ttc_index.py` 的说明）。
