# Word 一键水印工具（WriteMark）

一个用 Python + PySide6 编写的 Windows 小工具：对 Word 文档 **一键插入/清除水印**，
支持 **文本水印与图像水印同时叠加**、**中文字体/西文字体分别设置**、**上下左右偏移**，
并带 **后台守护（水印被删自动补回）** 与 **无需打开 Word 的实时预览**。可打包为独立 `.exe`，双击即用。

## 功能

- **文本 + 图像水印可同时叠加**
  - 文本水印：自定义文字、**中文字体 / 西文字体分别指定**、字号、颜色、旋转角度、透明度、缩放。
  - 图像水印：自定义图片、旋转角度、透明度、缩放。
  - 两类水印各有 **独立的一套参数**（角度/透明度/缩放/偏移互不干扰）。
- **Word 式“中文字体 / 西文字体”分别设置**
  - 汉字、中文标点走中文字体；字母、数字、半角符号走西文字体。
  - 例：`机密 CONFIDENTIAL` 可设为“机密=仿宋，CONFIDENTIAL=Times New Roman”，与 Word 字体对话框语义一致。
  - 两个字体框都 **可直接键入筛选**（输入 `t` 出 Times New Roman，输入 `仿` 出仿宋）。
  - 导入 Word 后可授权读取本机可用字体（Word 在场时约 1400 种）扩充下拉框；仅读取字体名，不访问文档内容。
- **上下左右偏移**：文本与图像水印都能按页宽/页高百分比做水平/垂直偏移。
- **一键清除**：既能清掉本工具加的水印，也能清掉 **Word 原生水印**（衬于文字下方的图形）。
- **不破坏原文件**：默认 **另存为** `桌面/<原名>_水印.docx`，原文件保持不变，输出路径可自定。
- **后台守护（防篡改）**：按设定间隔检查，水印被删则自动补回；**支持按份数校验**（水印被删掉一部分也整体补齐）；
  可 **最小化到系统托盘常驻**——关掉主窗口后守护继续在后台运行。
- **防去除加固（可选）**：见下方 [专节](#防去除加固能挡住什么挡不住什么)。
  - **平铺满页水印**：从“单个居中”改为整页多行多列平铺，抹除难度陡增。
  - **多份冗余嵌入**：页眉 + 页脚都写入，且图形显示名不含 `watermark` 字样。
- **实时预览**：改任意参数约 0.2 秒后自动刷新 A4 示意预览，可导出 PNG。

## 环境要求

- **Windows** 操作系统。
- **兼容 WPS Office 与 Microsoft Word**（水印为标准 OOXML “页眉中衬于文字下方的图形”）。
- **`.docx`**：无需安装 Word/WPS，纯 Python 处理，便携性最好。
- **`.doc`（Word 97-2003）**：**必须本机安装 Microsoft Word**（走 Word 自动化，纯 Python 无法读写 `.doc`）。

## ⚠ 操作前必读：先关闭 WPS/Word

- 插入/清除前请 **完全退出 WPS/Word**；文件被占用时工具会明确提示而不是默默失败。
- **WPS 关闭窗口后进程可能仍驻留后台并锁定文件**：可在任务管理器结束 `wps.exe` 后重试。
- 开启“守护”时，文件被占用期间守护会自动暂停读写，待空闲后自动恢复，不与编辑器争抢文件。

## 使用

运行 `WordWatermark.exe`（或 `python main.py`）：

1. 点“浏览...”选择 Word 文件（`.docx` / `.doc`），程序自动给出默认输出路径（桌面/<原名>_水印.docx）。
2. 需要改名/改位置就点“输出”右侧的“浏览...”（**不会覆盖原文件**；若输出设为与源文件相同，会自动加 `_水印` 后缀保护原文件）。
3. 勾选“启用文本水印”/“启用图像水印”（可同时启用），分别设置各自参数。
4. 文本水印里分别选 **中文字体** 与 **西文字体**，调字号、颜色；用“水平/垂直偏移”调整位置。
5. **实时预览**：改任意参数约 0.2 秒后预览区自动刷新，无需点按钮。
6. 点 **一键插入水印** 或 **一键清除水印**（在新文件上操作，原文件不变）。
7. 需防篡改就勾选“启用守护”并设置检查间隔（默认 1 秒，最小 0.2 秒），取消勾选即停止。

> **插入后看不到水印？** 依次检查：
> 1. Word 必须处于 **页面视图 / 打印布局**（“草稿”或“Web 版式”不显示页眉水印），WPS 对应 **页面布局** 视图。
> 2. 文件是否正被 Word/WPS 打开（会被锁定导致保存失败，先关闭再操作）。
> 3. 处理 `.doc` 时本机必须装有 Word（缺 Word 会弹窗报错）。

## 防去除加固：能挡住什么、挡不住什么

先说结论，避免期待落空：**没有任何方案能保证水印"绝对删不掉"**。本工具做的是把"删水印"的成本抬高，并挡住最常见的几条路径。

| 加固项 | 挡住谁 | 原理 |
| --- | --- | --- |
| **平铺满页水印** | **PS 内容识别填充 / AI 修图去水印** | 稀疏的单个居中水印，AI 很容易抹掉且不留痕迹；覆盖整页的密集纹理要想去掉，等于把整页重画 |
| **多份冗余嵌入**（页眉+页脚） | 在 Word/WPS 里点"删除水印"、或只清页眉的脚本 | 页眉那份被删了，页脚那份还在；每个 part 还有 N 份 |
| **伪装显示名**（不含 `watermark` 字样） | 按名称/结构匹配的去水印宏与脚本 | 它们按名字找水印图形，认不出我们的图形 |
| **守护按份数校验** | 手动删掉一部分的人 | 份数一少就整体补齐 |

**必须说清的三个边界：**

1. **守护只对"你自己机器上的那个文件"有效。** 它是个自愈监控进程，不是加密。文件一旦发给别人，别人手里那份跟你机器上的守护没有任何关系。
2. **PS 打不开 `.docx`。** 别人用 PS/AI 去水印，路径必然是 `docx → 导出 PDF/图片 → 修图 → 再导出`。到修图那一步，水印已经是**像素**，docx 里的任何结构（名字、份数、保护）都已不存在——**此时只有"平铺"这一项还起作用**，因为它是唯一让水印在像素层面难以清除的手段。
3. **`.docx` 本质是个 zip。** 任何拿到文件的人都能解压、改 XML、重新打包。因此任何"docx 层面的保护"都是提高门槛，不是绝对防线。

## 如何验证“后台守护”

守护监控的是**输出文件**：只要它的水印没了、份数少了、或文件被整个删除，就自动从**源文件**重新生成补回。

两点注意：
- 守护在**工具运行时**工作。关掉主窗口时会**最小化到系统托盘**（右键托盘图标可显示窗口 / 停止守护 / 退出程序），守护继续在后台跑；只有从托盘选"退出程序"或取消勾选"启用守护"才会真正停止。
- 输出文件正被 Word/WPS 打开时会自动暂停（日志会提示"文件被占用，守护暂停读写"）。

### 手工验证（最直观，1 分钟）

1. 准备一个测试文档 `test.docx`（随便写几行字）。
2. 工具里选择它 → 输出设为 `桌面\test_守护.docx` → 勾选“启用文本水印”，文字填“机密 TEST”。
3. 点 **一键插入水印**，打开输出文件确认已有水印。
4. 勾选 **启用守护**，检查间隔设为 0.5 秒，然后**保持工具窗口开着**。
5. 任选一种方式把水印弄掉：
   - **方式 A（模拟被人清除）**：在 Word 里打开输出文件 → `设计/页面背景 → 水印 → 删除水印` → 保存 → **关闭 Word**（关掉后文件才不被锁，守护才会动）。
   - **方式 B（手动删除）**：双击页眉进入编辑 → 选中水印图形 → Delete → 保存并关闭 Word。
   - **方式 C（删文件）**：直接把 `test_守护.docx` 删掉。
   - **方式 D（只删一部分，验证按份数校验）**：勾选"平铺满页 + 多份冗余嵌入"插入后再开守护（此时会写入很多份），然后在 Word 里只删掉其中几个图形并保存关闭。
6. 等待约 1 秒（不超过一个检查周期），重新打开输出文件：水印应已自动回来（方式 C 会连文件一起重建）。
7. 工具下方日志区会打印下列之一：
   - `⚠ 检测到水印被移除，已自动从原文件补回。`
   - `⚠ 检测到水印被部分移除（3/16 份），已自动补齐。`（方式 D）
   - `⚠ 输出文件已被删除，已自动从原文件重新生成并加水印。`（方式 C）
   - `· 水印在位。`（一切正常，仅状态行显示）
8. 取消勾选"启用守护"即停止；关掉主窗口则最小化到托盘继续运行。

### 自动验证（无需手工操作）

## 从源码运行 / 打包

依赖：`python-docx`、`Pillow`、`pywin32`、`PySide6`、`PyInstaller`。

```bat
python main.py                       :: 直接运行
build.bat                            :: 或用 PyInstaller 打包
pyinstaller WordWatermark.spec       :: 使用仓库内的 spec（单文件、无控制台窗口）
```

产物在 `dist/WordWatermark.exe`（单文件，可拷贝到任意 Windows 机器运行；处理 `.doc` 的机器仍需安装 Word）。

仓库内 `test_*.py` 为无界面（offscreen）自动化测试，可用 `python test_word_fonts.py` 等方式逐个运行。

## 标记与安全性说明

- 本工具用 `WB_WATERMARK_TEXT`（文本）/ `WB_WATERMARK_IMG`（图像）标记自己插入的水印：
  - **未开加固**时，标记直接写在图形的显示名（`wp:docPr/@name`）上；
  - **开了"多份冗余嵌入"**（伪装模式）时，显示名改成 `图片 101`、`Image 102` 这类普通插图名，
    私有标记改存到 `wp:docPr/@descr`（Word 中对应"替换文字/Alt Text"）。
    该属性是 OOXML 标准属性，实测 **Word 打开并另存后依然保留**，因此识别与一键清除不受影响。
- **清除**时会同时移除本工具标记的水印，以及任何"衬于文字下方"的图形（即 Word 原生水印），页眉与页脚都会扫描。
- 不会动正文、图片、表格等其它内容。

## 已知限制

- `.doc` 必须由装有 Word 的机器处理（格式限制，非本工具缺陷）。
- 目标文件正被 Word 打开时，插入/清除可能因文件锁失败；建议先关闭，或由守护在空闲时补回。
- 守护会周期性读写文件，文件很大或磁盘慢时请调大检查间隔。
- 字体完整列表依赖本机装有 Microsoft Word；仅 WPS 环境会自动改用系统字体（数量仍远超内置项）。
- **水印无法做到"绝对删不掉"**。`.docx` 本质是 zip，任何拿到文件的人都能解压改 XML；一旦导出成图片，
  更是只剩像素。加固项的作用是抬高门槛，不是加密。详见 [防去除加固](#防去除加固能挡住什么挡不住什么)。
- 开了平铺后单页水印图形数量 = 行列数 ×（页眉份数 + 页脚份数）。份数过多时，Word 打开稍慢、文件略大
  （图片本身按内容去重，不会成倍增长）；默认 5×2 已能覆盖整页。
- 系统托盘常驻需要桌面环境支持托盘图标（Windows 默认支持）。
